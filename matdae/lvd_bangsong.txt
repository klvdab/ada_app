이름: 배리어프리방송국·배프 → LVD 방송 / BYOD·공유기방송 → 현장 방송 / 라이브 현장영상해설·인터넷 생방송 → 인터넷 방송 / TV해설방송·다시 듣기·교육 녹화는 그대로
표시: 옮김 = 자리만 옮김 / 그대로 / 새로 = 이번에 새로 생김 / 합침 = 둘을 하나로

가. 웹 대문 (lvd.ada.or.kr/bfb)
1. 라이브 현장영상해설 듣기 → 「지금 현장영상해설 듣기」 (이름)
2. TV해설방송 듣기 → 그대로
3. 다시 듣기 → 그대로
4. 방송 알림 받기(듣기 화면 안에 있던 것) → 대문에도 단추 (새로, 듣기 화면의 알림 받기로 바로 감)
5. TV방송, 라디오방송 → 「그 밖에 들을 거리」 펼치기 안 (옮김)
6. 도움말(소개 펼치기 안에 있던 것) → 대문 단추 (옮김)
7. 새로고침 → 그대로
8. LVD 방송 앱 받기 → 그대로
9. 현장영상해설이란 펼치기 → 듣는 분 이야기만 남김. 「해설사는 어떻게 방송합니까」 다섯 단계는 방송하기 화면으로 (옮김)
10. 지금 방송 중 알림 줄 → 옛 방식(live.php)을 보던 것을 새 중계로 보게 고침 (고침)
11. 관리자 — 교육 녹화, 현장 해설방송 → 방송하기 화면으로 (합침)
12. 현장영상해설사 방송하기 → 맨 아래 작은 한 줄 (그대로)

나. 웹 방송하기 (lvd.ada.or.kr/bfb/haeseolsa.html)
1. 현장 방송 (행사장) → LVD 송출 앱으로 한다는 안내와 앱 받기 (새로)
2. 라이브 현장영상해설 하기 → 「인터넷 방송 하기」 (이름)
3. TV해설방송 하기 → 그대로
4. 현장영상해설교육 녹화 (관리자만) → 그대로
5. 현장 해설방송 — 인터넷 없이 (노트북, 관리자만) → 「더 보기」 안 노트북 현장 방송(예비) (옮김)
6. 방송하는 방법 → 대문에서 옮겨 온 다섯 단계 (옮김)
7. 옛 「배프 관리자」 화면(bfblive/gwanri) → 방송하기 화면으로 넘겨 주는 안내판, 옛 파일은 그대로 둠 (합침)

다. 웹 안쪽 화면 제목
1. 듣기·TV해설 듣기·다시 듣기·방송·인터넷 방송 하기·TV해설 하기·교육 녹화·도움말의 「배리어프리방송국」 → 「LVD 방송」
2. 뒤로 단추 이름 「방송국 첫 화면」·「배리어프리방송국 첫 화면」 → 「LVD 방송 첫 화면」
3. 화면의 기능·주소·저장 열쇠는 그대로 (이름만 바꿈)

라. 듣는 앱 LVD 방송 (아이폰·안드로이드) 2.1.0 → 2.2.0
1. 현장영상해설 듣기(행사장) → 「지금 현장영상해설 듣기」 하나: 행사장이면 현장 방송, 아니면 인터넷 방송을 저절로 골라 앱 안에서 틂 (합침)
2. 인터넷 생방송 듣기(더 보기, 누리집 화면) → 1번에 합침. 여러 방송이 함께 나가면 고르기, 누리집 화면도 더 보기에 남김 (합침)
3. 현장영상해설사 도움 요청 → 그대로 (행사장에서만)
4. 행사장에 들어서면 저절로 들리게 하기 → 그대로
5. 새 판 한 줄 → 그대로
6. 지난 방송 다시 듣기 → 「다시 듣기」 첫 화면으로 (옮김)
7. TV해설방송 듣기 → 첫 화면으로 (옮김)
8. 방송 알림 받기 → 더 보기 (새로, 누리집 듣기 화면의 알림 받기)
9. TV방송·라디오방송 → 더 보기 안 「그 밖에 들을 거리」 (옮김)
10. 저절로 듣기 켜고 끄기, 와이파이 저절로 붙기 다시 하기, 말소리, 도움말, 새로고침, 업데이트, 판 정보 → 그대로 (더 보기)
11. 도움말 → 새 차례·새 이름에 맞게 고치고 「지금 현장영상해설 듣기」「인터넷 방송」 항목 고침

마. 보내는 앱 LVD 송출 (아이폰·안드로이드) 1.4.0 → 1.5.0
1. LVD 송출 시작 → 「현장 방송 시작」 (이름). 켜면 인터넷 방송도 함께 나감 (새로), 끝나면 다시 듣기에 남음(그대로)
2. 행사 이름·현장영상해설사 이름 칸 → 그대로, 현장영상해설사 전화번호 칸 (새로 — 인터넷 방송에 필요)
3. 현장 점검 → 그대로
4. 라이브 현장영상해설 방송 (인터넷) → 「인터넷 방송만 하기」 (이름)
5. TV해설방송 하기 → 첫 화면 (새로, 웹 화면을 앱 안에서)
6. 현장영상해설교육 녹화 → 그대로
7. 더 보기: 접속 도구, 지난 행사 기록, 공유기 방송 서버 확인(아이폰), 플린트 2 준비하기(안드로이드), 방송 방식 바꾸기, 기기 점검, 새로고침, 업데이트, 말소리, 도움말, 판 정보 → 그대로
8. 노트북 현장 방송(예비) → 웹 방송하기 「더 보기」에 둠 (앱에는 없던 것)
9. 다시 듣기에 같은 행사가 두 번 나오지 않게 — 인터넷으로 나간 녹음 대신 공유기의 온전한 녹음 하나만 남김 (새로)
10. 도움말 → 현장 방송·인터넷 함께·전화번호·인터넷 방송만 하기·TV해설방송 항목 고침과 더함
