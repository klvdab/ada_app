판 2.3.0 / 빌드 261019-L4 / 2026-10-19 (이사장님 결정 — LVD 방송 저녁 일, 방클)
- 앱 안 누리집에 「LVDBangsong」 표지(사용자 에이전트) — 다시 듣기 내려받기가 앱에서는 소리 mp3 두 가지(들으시는 그대로·원본)와 받아쓰기 글만, 「영상은 컴퓨터의 웹에서 받으실 수 있습니다」
- 내려받기를 앱 안에서: 와이파이가 아니면 「데이터로 ○○메가를 받습니다. 받을까요?」 먼저 물음 — 안드로이드 DownloadManager 로 다운로드 폴더(9 이하는 저장 허락)
- 다시 듣기도 화면을 잠가도 이어짐, 전화가 울리거나 통화 중이면 누리집 소리를 멈추고 끝나면 이어 틂
- 「현장 방송」「공유기 방송」을 「BYOD 방송」으로, 도움말의 옛 이름 줄을 뺌, 도움말 네 항목 더함(차례와 건너뛰며 듣기·내려받기·받아쓰기 글·화면 잠그기와 전화)

판 2.2.0 / 빌드 261018-L3 / 2026-10-18 (이사장님 승인 「1」 — LVD 방송 정리안, 방클) — 아이폰 2.2.0과 같음
- 「지금 현장영상해설 듣기」 하나로: 행사장이면 현장 방송, 아니면 중계(lvd.ada.or.kr:2053) /moklok 에서 지금 나가는 방송을 찾아 /mp3 를 MediaPlayer 로(DeutService 안, 알림 줄·잠금에도 이어짐)
  하나면 바로, 여럿이면 첫 화면에 고르기(Deut.gorgi/goreun), 없으면 알리고 10초마다, 인터넷으로 듣다 행사장 와이파이에 붙으면 현장 방송으로, 방송이 끝나면 알리고 다른 것을 찾음
- 첫 화면: 지금 현장영상해설 듣기, 상태, (고르기), TV해설방송 듣기, 다시 듣기, 도움 요청(행사장에서), 새 판, 저절로 들리게 하기, 더 보기
- 더 보기: 방송 알림 받기, 인터넷 방송 목록(누리집), 그 밖에 들을 거리(TV방송·라디오방송) 펼치기, 그 밖에는 그대로
- 도움말 다섯 고침, 둘 더함

판 2.1.0 / 빌드 261016-L2 / 2026-10-16 (이사장님 승인 "1", 방클)
- 더 보기에 TV해설방송 듣기(lvds/haeseol_deutgi)·TV방송(chae?kind=tv)·라디오방송(chae?kind=radio) 넣음 — 옛 배프 웹에서 듣던 것을 앱에서도 같게
- 「인터넷으로 배리어프리방송국 생방송 듣기」를 「인터넷 생방송 듣기」로 줄임
- 앱 안 누리집 화면: 누리집 쪽 뒤로 단추(.dwiro-btn·#btnDwi1·#btnDwi2·#homeBtn)를 감추어 앱의 뒤로만 남김, 뒤로 가기는 늘 앱 첫 화면으로
- 도움말 세 항목(TV해설방송 듣기·TV방송·라디오방송) 더함

판 2.0.0 / 빌드 261015-L1 / 2026-10-15 (이사장님 승인 "1", 방송클)
- 배프 웹 껍데기(MainActivity, 1.2.1)를 속까지 앱으로 새로 지음. 앱 번호를 이어 배프 앱을 깔아 둔 폰은 업데이트로 LVD 방송이 됨
- 이사장님 뜻: 듣는 분께는 들을 것만 — 방송 방식·공유기 같은 말은 어디에도 보이지 않게
- 첫 화면: 협회 로고 머리, 현장영상해설 듣기(큰 단추, 커서), 상태 한 줄(바뀔 때만 알림), 현장영상해설사 도움 요청(누르면 바로 아래 세 가지), 처음 한 번 허락, 새 판 한 줄, 더 보기
- 더 보기: 인터넷 배리어프리방송국 생방송(앱 안 누리집 화면), 지난 방송 다시 듣기, 저절로 듣기 켜고 끄기, 와이파이 저절로 붙기 다시 하기, 프로그램 말소리, 도움말, 새로고침, 업데이트, 판 정보
- 행사장 와이파이 저절로 붙기: WifiNetworkSuggestion(현장영상해설방송, 비밀번호 없음). 붙으면 안드로이드가 알려 줌(WIFI_NETWORK_SUGGESTION_POST_CONNECTION, 위치 허락 필요) → 듣기 일꾼을 켜거나, 막히면 「행사장에 오셨습니다」 알림
- 앱이 열려 있으면 3초마다 행사장인지 살펴 저절로 듣기(손으로 멈춘 때는 행사장을 벗어날 때까지 다시 켜지 않음)
- 듣기 일꾼(DeutService, mediaPlayback): 행사장 망(192.168.8~11)으로만 /stream(뮤 16000) 받아 AudioTrack 으로 틂. 인터넷은 모바일 데이터 그대로
- 전화: 소리 자리(오디오 포커스)를 잃으면 멈추고 돌아오면 다시. 통화 상태(AudioManager mode)도 함께 봄. 다른 앱이 소리 자리를 아주 가져가면 다투지 않고 멈춤
- 벗어남: 8초 넘게 행사장 망이 없으면 「현장 방송에서 벗어났습니다」 한 번, 돌아오면 「다시 연결되었습니다」
- 같은 폰 LVD 송출: 송출 중 알림(kr.or.ada.permission.SONGCHUL, 서명 권한)을 받으면 이어폰일 때만 틂
- 도움 요청: 공유기 /yocheong(dowum·kkeunkim·gungeum) — 송출 앱 첫 화면에 바로 뜸
- 새 판 알림: Ollim(LVD 송출과 같은 부품, 갈래 bfb). 앱 스토어 정식 출시 뒤에는 스토어 자동 업데이트
- 아이콘: 남색 바탕 로고 아래 흰 「방송」(icon-1024.png, android/tools/make_android_icon.py 가 이것을 씀)
- 다음 판에: 협회 소식 알림(푸시, 받지 않기 선택), 전화로 듣기(번호를 걸면 방송이 들림)
